# Assets tab

<Art name="tree" size={95} />

**Assets** are the files your game uses: images (textures), 3D models, sounds and fonts. They are stored inside the project, so an exported game or a backup carries them along.

<Side shot="assets-tab-coins">

- The chips at the top filter by kind: **All**, **Images**, **Models**, **Sounds**, **Fonts**.
- **🌐 Free assets** opens the [model library](../world/models#free-models-library).
- **🔊 Free sounds** opens the free sound library, **🎛 Make a sound** in it the [sound maker](../world/sound#make-a-sound), **🥁 Make a beat** the [beat maker](../world/sound#make-a-beat) and **🎹 Make music** the [music editor](../world/sound#make-music).
- **⬆ Import** picks files from your phone.

</Side>

## Supported files

| Kind | Files | Used by |
| --- | --- | --- |
| 🖼️ **Images** | PNG, JPG, WebP, GIF… | Textures on shapes, UI images, particle textures, sky images, the app icon |
| 🧊 **3D models** | `.glb` (recommended), `.gltf` (single file only) | Shape & look → *3D model* |
| 🔊 **Sounds** | MP3, OGG, WAV, M4A | Sound component, *Play sound* action |
| 🔤 **Fonts** | TTF, OTF, WOFF, WOFF2 | The **Font** of UI text and Text labels (see [Fonts](../world/ui#fonts)) |

:::tip[Keep files small]
Everything is stored on the phone and packed into exported games. Prefer compressed images (JPG/WebP, 1024 px or less) and short MP3/OGG sounds.
:::

## Asset menu

Tap an asset to open its menu:

| Item | Appears for | What it does |
| --- | --- | --- |
| **Add to scene** | Models | Places the model in the scene. |
| **Apply to ‹object›** | Images, when a shape is selected | Uses the image as that object’s texture. |
| **Preview sound** | Sounds | Plays it, with a player bar at the bottom: tap the bar to stop. A beat saved as a loop (🔁) repeats, as it will in the game. |
| **Edit sound** | Sounds made with the [sound maker](../world/sound#make-a-sound) (or by Claude) | Opens it in the sound maker again; **Save** changes it in place. |
| **Compress…** | Sounds that aren't OGG yet (imported WAVs, older made sounds) | Makes it OGG at a quality you pick (**Smaller**, **Balanced**, **Best**), about 10 times smaller; everything using it plays the new file. See [Sound files](../world/sound#sound-files). |
| **Edit beat** | Beats made in the [beat maker](../world/sound#make-a-beat) | Opens the beat again; **Done** changes the sound in place. |
| **Edit music** | Music made in the [music editor](../world/sound#make-music) | Opens the song again; **Done** changes the sound in place. |
| **Rename** | All | Renames it (names are used by *Play sound* and scripts). |
| **Delete** | All | Deletes it; tells you how many objects use it first. Objects using it lose the reference. |

The card shows the file size. Models from the free library show their thumbnail, and a font shows **Aa** drawn in that font.
