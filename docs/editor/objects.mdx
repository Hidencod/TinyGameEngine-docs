# Objects tab

<Art name="cube-grass" size={105} />

The Objects tab lists every object in the scene you are editing, and is where you add new ones.

<Side shot="objects-tab-empty-scene">

<Legend items={[

  <><b>Object rows</b> — tap to select. Children are indented under their parent.</>,

A new project has a **Camera**, a **Sun** light and a **Ground**.

</Side>

## Object rows

Each row has an icon showing what the object is (🎥 camera, 💡 light, 🧊 shape or model, 🖼 UI, 🔤 text, ✨ particles, 🔊 sound, ○ empty).

<Row>
  <Crop name="objects-selected-row" caption="Selected row: tap Edit › to open the Inspector" width={320} />
  <Crop name="objects-hidden-row" caption="👁 hides an object in the editor and the game" width={320} />
</Row>

- **Tap** a row to select it; tap the selected row again (or **Edit ›**) to open the [Inspector](./inspector).
- **👁** hides or shows the object. Hidden objects are not drawn in the game either, but still exist — events can show them again.
- **⋮** opens the object menu.
- A **▾ / ▸** arrow before a parent folds or unfolds its children.
- **Drag a row** to reorganize: drop it onto the **middle** of another row to make it that object's child, onto a row's **top or bottom edge** to move it before or after, or onto the **empty space below the list** to bring it back to the top level. With a mouse, just drag; on a phone, **press and hold** a row a moment, then drag (a quick swipe still scrolls). It stays where it is in the 3D world. On-screen UI and 3D objects can't be mixed.
- Greyed-out rows are **inactive** objects (see the Inspector’s *Active* switch).

Tap **＋ Add**. New objects appear in the middle of the view.

## Object menu {/* #object-menu */}

<Side shot="object-menu">

Tap **⋮** on a row, or **long-press** the object in the 3D view.

| Item | What it does |
| --- | --- |
| **Edit properties** | Opens the Inspector. |
| **Rename** | Names use letters, numbers and `_` so events can refer to them. |
| **Duplicate** | A copy with the **same name** — an extra instance of the same object type. |
| **Focus in view** | Centers the 3D view on it. |
| **Move up / down** | Reorders the list (also the drawing order of UI). |
| **Set parent…** | Attaches it to another object so they move together. |
| **Unparent** | Detaches it again. |
| **Make prefab** | Saves it (with its children) as a reusable prefab. |
| **Delete** | Deletes it and its children (undo brings them back). |

</Side>

:::tip[Same name = same type]
Objects with the same name are **instances of one object type**. An event about `Coin` works on every coin — see [How events work](../logic/event-sheets). Give *different* things different names.
:::

## Prefabs

<Side shot="objects-prefabs">

A **prefab** is a saved object (with its children, components, behaviors and variables) that you can place again and again, and that events can **create while the game runs** (*Create object* action) — bullets, enemies, coins.

- **Make prefab** from the object menu.
- The **Prefabs** list appears under the objects. **＋ Place** adds a copy to the scene; 🗑 deletes the prefab (copies already placed stay).
- Prefabs also appear in the **＋ Add** menu.

</Side>
