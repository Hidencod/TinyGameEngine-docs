# Editor overview

<Art name="panel-scene" size={150} />

When you open a project you see the editor. It has three areas: the **top bar**, the **3D view** of your scene, and the **dock** with five tabs at the bottom.

<Side shot="editor-overview-annotated">

<Legend items={[
  <><b>Top bar</b> — the project sidebar (☰), project name, undo/redo, Play.</>,
  <><b>Viewport tools</b> — move/rotate/scale, snap, multi-select, focus, colliders, UI mode. See <a href="./viewport">The 3D view</a>.</>,
  <><b>3D view</b> — your scene as it looks in the game. Tap to select, drag to look around.</>,
  <><b>Split handle</b> — drag to resize the two areas; tap to hide the dock and get a big 3D view.</>,
  <><b>Dock tabs</b> — Objects, Inspect, Assets, Logic, Scene.</>,
  <><b>Tab content</b> — the open tab.</>,
]} />

</Side>

## Top bar

<Crop name="editor-topbar-annotated" width={420} />

<Legend items={[
  <><b>☰</b> — the project sidebar: settings, scenes, build, backup, help, and <b>Close project</b> to go back to the home screen. See <a href="#the-project-sidebar-">below</a>.</>,
  <><b>Project name</b> — tap to rename the project.</>,
  <><b>↶ Undo</b> — undo the last change (every change can be undone).</>,
  <><b>↷ Redo</b> — redo what you undid.</>,
  <><b>⚙ Project settings</b> — orientation, controls, graphics, physics. See <a href="./project-settings">Project settings</a>.</>,
  <><b>▶ Play</b> — play the game from its start scene. See <a href="./play-mode">Play mode</a>.</>,
]} />

:::info[Saving]
Every change is saved on the device automatically a moment after you make it. The **save button** (the disk at the top right) is bright while there are changes not saved yet and dull once they are; tap it, or press **Ctrl + S** on a computer, to save at once. On desktop Chrome and Edge it also saves the project to a [.tge file](../publish/backup#where-projects-are-kept), and stays bright until the file has the changes.
:::

## Resize or hide the dock

Drag the **split handle** (the small bar between the 3D view and the tabs) up or down to give more room to either side. **Tap** it to hide the dock and use the whole screen for the 3D view; tap it again (or any tab) to bring the dock back. The editor remembers your layout.

<Row>
  <Phone name="editor-overview" caption="Normal" />
  <Phone name="editor-dock-collapsed" caption="Dock hidden: big 3D view" />
</Row>

**Landscape:** turn the phone sideways and the 3D view goes on the left with the dock on the right.

## The project sidebar (☰)

<Side shot="editor-project-menu">

Tap **☰** at the top left. The sidebar groups everything about the project:

| Group | Items |
| --- | --- |
| **Project** | [Project settings](./project-settings) (the **▾** beside it lists its sections: tap one to open the settings there), [Scenes](./scenes), [GitHub](../publish/github-sync), Rename project. |
| **Play** | Run project (from the start scene), Run this scene (from the scene you are editing). On a computer also *Play mode*. See [Play mode](./play-mode). |
| **Share** | [Publish game (link)](../publish/publish-link), [Build](../publish/build) (Web or Android). |
| **Save** | Save, [Backup project (.tge)](../publish/backup), Project as folder (.zip). |
| **Editor** | Editor layout (phone or desktop), Editor density (**Compact** has smaller text with more room around it, like Unity; on a computer it is on by default, on a phone it is something to try); on a computer *Keyboard shortcuts*. |
| **Help** | Documentation, What's new, [Help & feedback](../help/feedback). |

**Close project** at the bottom goes back to the home screen. Your work is already saved. Tap outside the sidebar (or press Back or Escape) to close it.

On a computer the **File · Edit · Object · View · Scene · Help** menus beside **☰** hold the same actions, with their keyboard shortcuts.

</Side>
