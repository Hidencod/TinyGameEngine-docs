## General

| Field | What it does |
| --- | --- |
| **Project name** | Also the default app name when exporting. |
| **Start scene** | The scene the game begins with. |
| **Screen orientation** | **Landscape** (sideways), **Portrait** (upright) or **Any**. Play mode and exported games lock to it. |
| **App icon** | An image used as the launcher icon of exported APKs. A square image works best. |

## Graphics & performance

| Field | What it does |
| --- | --- |
| **Starts at quality** | The level a game starts at: Low, Medium or High (below). |
| **Edit level** | Which level the fields below show and change. |
| **Max pixel ratio** | How sharp the game is drawn (0.5–3). Lower is faster and blurrier; **1–1.5 is good for cheap phones**. |
| **Smooth edges (antialias)** | Smoother edges, slower on low-end phones. The editor applies it after reopening the project. |
| **Shadows** | Turn all shadows on or off. Off is much faster. |
| **Max particles** | The most particles alive at once, all effects together. Keeps cheap phones smooth. |

### Quality levels

Like Unity's Quality Settings, the game has three levels: **Low**, **Medium** and **High**. Each is a set of the fields above (plus **Glow (bloom)** for Low and Medium: off means the scene's glow is not drawn).

- **High** is your project's own settings, the ones you had before.
- **Medium** and **Low** start as lighter versions of High (a lower pixel ratio, no smooth edges; Low also has no shadows and no glow, and fewer particles). Pick **Edit level** and change anything.
- The scene's own **Glow (bloom)** stays your choice: a level can switch it off but never force it on.

The game starts at **Starts at quality**, or at the level the player chose last time (it is saved on the device). Let players change it with events or a script:

- Event actions (group **Graphics**): *Set graphics quality*, *Set resolution scale*, *Set shadows*, *Set glow (bloom)*, *Set max particles*, *Set antialiasing (smooth edges)*, and the condition *Graphics quality is*.
- Scripts: `game.quality.level = "low"`, or one setting: `game.quality.pixelRatio = 1`, `.shadows = false`, `.glow = false`, `.maxParticles = 300`.

Setting a level also resets the single settings to that level. **Smooth edges (antialiasing)** can only change when the game starts, so a new value counts from the next start; **glow** can be switched off any time, but switched on again only if the game started with glow allowed. Use **Play → fps** and its draw-call line to see what a level saves.

See [Performance tips](../help/performance).

## Physics

**Gravity** — X, Y, Z in m/s². Earth is `0, -9.82, 0` (**Reset to Earth**). Try `0, -4, 0` for a moon, or a sideways gravity for a strange world.

## Touch controls

The joystick and on-screen buttons — the same editor as in the [Scene tab](./scene-tab#touch-controls).
