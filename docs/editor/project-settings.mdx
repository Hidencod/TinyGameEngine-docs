## General

| Field | What it does |
| --- | --- |
| **Project name** | Also the default app name when exporting. |
| **Start scene** | The scene the game begins with. |
| **Screen orientation** | **Landscape** (sideways), **Portrait** (upright) or **Any**. Play mode and exported games lock to it. |
| **App icon** | An image used as the launcher icon of exported APKs. A square image works best. |

## Graphics & performance

| Field | What it does |
| --- | --- |
| **Level chips** | The quality levels of the project (Low, Medium and High to start with). The open one is the level the fields below show and change (see [Quality levels](#quality-levels)). |
| **Starts at quality** | The level a game starts at (also marked ★). |
| **Max pixel ratio** | How sharp the game is drawn (0.5–3). Lower is faster and blurrier; **1–1.5 is good for cheap phones**. |
| **Smooth edges (antialias)** | Smoother edges, slower on low-end phones. The editor applies it after reopening the project. |
| **Shadows** | Turn all shadows on or off. Off is much faster. |
| **Max particles** | The most particles alive at once, all effects together. Keeps cheap phones smooth. |

### Quality levels

Like Unity's Quality Settings, the project has a **list of quality levels**. A new project starts with three: **Low**, **Medium** and **High**. The levels are the chips at the top of **Graphics & performance**; tap one to change everything it sets. **＋** adds a level (a copy of the last one), and **⋮** has *Rename*, *Duplicate*, *Start the game at this level*, *Move earlier* / *Move later* and *Delete* (a project always keeps at least one). A **★** marks the level the game starts at.

<Phone name="quality-levels-new" size="small" caption="The levels of the project, with a new one (Ultra) open for editing" />

<Phone name="quality-level-menu" size="small" caption="The level menu" />

Every level sets all of these:

| Setting | What it does at that level |
| --- | --- |
| **Max pixel ratio**, **Smooth edges (antialias)**, **Shadows**, **Max particles** | As above. |
| **Shadow picture size** | Sharpness of every light's shadow: 512, 1024 or 2048. Bigger costs more memory and time. |
| **Shadow cascades (most)** | The most cascades a sun's [Shadow cascades](../world/cameras-and-lights) may use: Off, 2, 3 or 4. Off gives a single shadow picture. |
| **Glow, Depth of field, Ambient occlusion, Edge smoothing, Color finish** | Whether that [screen effect](../world/post-processing#effects) may be drawn. A level can switch effects off but never adds one no volume has. *Color finish* is vignette, color fringe, saturation, contrast and colour grading. |
| **Mirror picture size** | The biggest reflection picture a mirror may have: Off (a mirror is plain metal), 128, 256, 512 or 1024. |
| **Glass** | Off: glass objects are plain surfaces, which is much faster. |
| **Lens flares** | Off: no lens flares. |

- **High** starts with everything on, **Medium** and **Low** start as lighter versions (Medium: a lower pixel ratio, 2 cascades, no depth of field or occlusion, small mirrors. Low: no shadows, no glow, mirrors and glass off, no lens flares, fewer particles; edge smoothing and color finish stay on because they are cheap). They are only where the list starts: change, rename or delete them as you like.
- The level the game starts at also sets the pixel ratio, smooth edges, shadows and particles you see in the editor view.
- Projects made before the list keep their Low, Medium and High with the values they had.

The game starts at **Starts at quality**, or at the level the player chose last time (it is saved on the device). Let players change it with events or a script. A level is named by its **id** (lower case: `low`, `medium`, `high`, or the name you gave a new level turned into letters, like `ultra`); scripts may also use its name or its position in the list:

- Event actions (group **Graphics**): *Set graphics quality*, *Set resolution scale*, *Set shadows*, *Set screen effects*, *Set max particles*, *Set antialiasing (smooth edges)*, *Set graphics option* (any single setting above: switches take 1 for on and 0 for off), and the condition *Graphics quality is*.
- Scripts: `game.quality.level = "low"` (reads back the id of the level in force), or one setting: `game.quality.pixelRatio = 1`, `.shadows = false`, `.shadowMapSize = 512`, `.cascades = 2`, `.glow = false`, `.depthOfField = false`, `.occlusion = false`, `.edgeSmoothing = true`, `.colorFinish = true`, `.mirrors = 256`, `.glass = false`, `.lensFlares = false`, `.maxParticles = 300`. `.effects = false` switches every effect off at once.

Setting a level also resets the single settings to that level. **Smooth edges (antialiasing)** can only change when the game starts, so a new value counts from the next start. Screen effects can be switched off any time, but switched on again only if the game could draw them from the start. Use **Play → fps** and its draw-call line to see what a level saves.

### Effects from scripts and events

**Effects from scripts and events** makes the game ready to draw screen effects even when no volume has one, so a script or an event can switch them on while playing (see [Post-processing](../world/post-processing#changing-it-while-playing)). It costs a little speed, so leave it off if you don't need it.

See [Performance tips](../help/performance).

## Physics

**Gravity** — X, Y, Z in m/s². Earth is `0, -9.82, 0` (**Reset to Earth**). Try `0, -4, 0` for a moon, or a sideways gravity for a strange world.

## Touch controls

The joystick and on-screen buttons — the same editor as in the [Scene tab](./scene-tab#touch-controls).
