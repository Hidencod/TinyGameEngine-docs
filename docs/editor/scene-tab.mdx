# Scene tab

<Art name="tree-small" size={85} />

The **Scene** tab holds settings for the whole scene you are editing, plus the project’s variables and touch controls.

<Side shot="dock-scene">

At the top: the scene you are editing (tap to switch — see [Scenes](./scenes)), a **★ Start scene** badge if the game starts here, and **⚙ Project** to open [Project settings](./project-settings).

The cards below can be folded by tapping their title.

</Side>

<Crop name="scene-tab-full" caption="The whole Scene tab (Roll-a-ball template)" width={340} />

## Scene

**Name** — the scene’s name, used by the *Go to scene* action.

## Environment

| Field | What it does |
| --- | --- |
| **Background** | **Color** (a plain color) or **Sky image (360°)**. |
| **Color** | The background color. |
| **Ambient light** | Color of the soft light that reaches everything, even in shadow. |
| **Ambient strength** | How strong it is (0–2). Lower it for a darker, moodier scene. |
| **Fog** | Fades far things into the fog color. Also hides the edge of big worlds and helps performance. |
| **Fog color / starts at / fully at** | Color, the distance where fog begins, and the distance where it is solid. |

### Sky image

<Side shot="sky-picker">

Choose **Background → Sky image (360°)** (or tap the sky image) and pick one of:

- **Free skies…** — day, morning, night, space, alien (by Kenney, free).
- **Import a 360° image…** — a 2:1 panorama (equirectangular) PNG, JPG or WebP.
- One of your project’s images.

</Side>

Then:

| Field | What it does |
| --- | --- |
| **Sky image** | Change the image. |
| **Turn sky** | Rotate the panorama (0–360°) to put the sun where you want it. |
| **Sky brightness** | 1 = the image as it is. |
| **Light with sky** | Objects with the **Realistic** material get reflections and soft light from the sky. |
| **Loading color** | Shown until the sky has loaded. |

## Scene variables

Values that exist only in this scene and **reset every time the scene starts** — e.g. a level timer. See [Variables](../logic/variables).

## Global variables

Values shared by **all scenes** and kept when you change scene — e.g. `Score`, `Lives`. New projects have a `Score` variable. Add with **+ Add variable**, choosing Number, Text or Yes / No.

## Touch controls

The on-screen controls shown while playing (also in [Project settings](./project-settings)):

| Field | What it does |
| --- | --- |
| **Joystick** | Show the virtual joystick. It drives the Platformer, Top-down and Car behaviors and the `joystickX` / `joystickY` values. |
| **Joystick side** | Left or Right. The buttons go on the other side. |
| **Buttons** | Round on-screen buttons. Each has a **Name** used by events, behaviors and scripts (e.g. `jump`), a **Label** shown on it (e.g. `A`), a **Color**, the **Keys** and **Gamepad** button that press it, and **On screen** (off = a keyboard / gamepad only button, e.g. `pause` on Esc). **Add button** adds one; 🗑 deletes it. Events can hide a button until it's useful and change its label with *Show*, *Hide* and *Set label* under **Input** — the same names as for UI buttons — see [getting into a boat](../behaviors#boat). |

<Side shot="controls-card" crop>

New projects have one button, `jump`, labelled **A**, pressed by **Space**, **J** and gamepad **A** — the Platformer behavior jumps with it (its **Jump button** setting names the button). WASD or the arrow keys and the left stick move.

**Keys:** tap **＋ Key**, then press the key on your keyboard (or pick one from the list on a phone); ✕ removes one. A button can have several keys, and the same key can press several buttons.

**Gamepad:** the button on a controller that presses it, or None.

A new button gets keys that suit its name — `use` / `interact`: **E** and **X**, `fire` / `shoot`: **F** and **RB**, `run` / `sprint`: **Shift** and **LB**, `pause`: **Esc** and **Start** — or the next free key (J, K, L…). Change them any time.

</Side>

**Gamepads** work in a browser and in exported games: the left stick or d-pad moves, and each button's **Gamepad** setting presses it. Every gamepad button also has its own name for *Key is held* / *On key pressed* and scripts: `PadA`, `PadB`, `PadX`, `PadY`, `PadLB`, `PadRB`, `PadLT`, `PadRT`, `PadStart`. The on-screen controls hide while a gamepad is used and come back on the next touch. The right stick turns a camera with [Mouse look](../behaviors#camera-follow).
