# Undo, gestures & shortcuts

## Undo and redo

Every change — moving an object, editing a field, adding an event, deleting a scene — can be undone with **↶** in the top bar and redone with **↷**. The event sheet and code editor have their own undo buttons too.

## Touch gestures

| Where | Gesture | Does |
| --- | --- | --- |
| 3D view | Drag | Orbit the view |
| 3D view | Pinch / two-finger drag | Zoom / pan |
| 3D view | Tap | Select an object |
| 3D view | Double-tap | Focus on the object |
| 3D view | Long-press an object | Object menu |
| 3D view (Move mode) | Drag the selected object | Slide it along the ground |
| Split handle | Drag / tap | Resize / hide the dock |
| Number fields | Drag sideways | Change the value |
| Event sheet | Tap / tap again / long-press | Select / edit / menu |
| Anywhere | Android Back | Close the open sheet, panel or play mode |

## Keyboard shortcuts

Useful with a Bluetooth keyboard or a Chromebook.

| Keys | Does |
| --- | --- |
| **Ctrl + Z** | Undo |
| **Ctrl + Y**, **Ctrl + Shift + Z** | Redo |
| **Ctrl + D** | Duplicate the selection |
| **Delete**, **Backspace** | Delete the selection |
| **Ctrl + A** | Select all 3D objects |
| **W / E / R** | Move / Rotate / Scale mode |
| **F** | Focus on the selection |
| **Esc** | Clear the selection |
| **Shift / Ctrl + click** | Add to or remove from the selection |
| **Ctrl + F** (event sheet) | Find in the sheet |
