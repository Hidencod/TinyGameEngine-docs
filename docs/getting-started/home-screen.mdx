# Home screen

<Art name="sprout-block" size={90} />

The home screen lists your projects and is where you start new ones. The bar at the bottom (a menu on the left on a computer) has **Projects**, **Learn** (the tutorials), **What's new**, **Help** and **Profile**.

<Side shot="home-empty">

The first time, there are three ways to start: **New project**, **Import from Git** and **Learn**.

</Side>

## Create a project

<Step n={1} title="Tap ＋ New project">

The template page opens. Every template is a complete, playable game (except *Empty 3D scene*). Scroll to see them all.

<Row>
  <Phone name="templates-picker" caption="Choose a template" />
  <Phone name="templates-picker-end" caption="…scroll for more" />
</Row>

</Step>

<Step n={2} title="Name it">

Type a name and tap **OK**. You can rename it later.

<Phone name="new-project-name" size="small" />

</Step>

<Step n={3} title="Start building">

The [editor](../editor/overview) opens with your new project. To come back here, open **☰** and tap **Close project**.

</Step>

See [Templates](../templates) for what each template contains and how it works.

### All projects

<Side shot="home-all-projects">

**See all** lists every project, most recently changed first.

- **Search** by name.
- **Grid / list** switches the view.
- **All**, **Recent** and **Favorites** filter the list; **＋** makes a group of your own (*Move to group* in the project menu puts a project in it; hold a group to rename or delete it).

Tap **←** or **Projects** to go back.

</Side>

### Project menu

<Side shot="project-menu">

| Item | What it does |
| --- | --- |
| **Open** | Opens the project in the editor. |
| **Rename** | Changes the project name. |
| **Move to group** | Puts the project in one of your groups (see *All projects*). |
| **Duplicate** | Makes a full copy (scenes, assets, events). Great before trying something risky. |
| **Backup (.tge)** | Saves the whole project as one `.tge` file you can keep or share. See [Backup](../publish/backup). |
| **Delete** | Deletes the project from this phone **forever** (asks first). |

</Side>

## Import a project

Tap **⬇** (next to *Import from Git*) and choose a `.tge` file (a backup made on this or another phone). It is added as a **new** project — it never overwrites one you already have.

## Help & feedback

<Side shot="help-menu">

Tap **Help** in the bar (also in the editor’s **☰** sidebar: *Help & feedback*).

| Item | What it does |
| --- | --- |
| **Guide & documentation** | Opens this guide. |
| **Use it on your computer** | The web address of the editor (Android app only). |
| **Send feedback** | Opens your email app with a message to the developer. Ideas and things that confused you are very welcome. |
| **Report a problem** | Same, and attaches the app’s recent error log to help fix the bug. |
| **Usage statistics** | Turns anonymous statistics on or off (Android app only). |
| **Privacy policy** | What the app keeps and sends. |
| **Open-source licences** | The libraries and free assets inside the app. |
| **Tiny Game Engine 1.x** | The version you have and the contact address. |

</Side>
