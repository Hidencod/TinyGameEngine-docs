# Install the app

<Art name="mushroom-small" size={90} />

Tiny Game Engine is an **Android app**. Everything — the editor, playing your game, exporting APKs — runs on the phone, offline. The same editor also runs [in a browser on your computer](#in-a-browser-on-your-computer).

## Requirements

| | |
| --- | --- |
| **Phone** | Android 7.0 or newer. Games are designed to run well on cheap phones too (see [Performance](../help/performance)). |
| **Storage** | About 15 MB for the app, plus your projects and assets. |
| **Internet** | Only needed for the free model, sound and sky libraries, and to send feedback. Everything else works offline. |

## Getting the app

The app is currently in **closed testing on Google Play**. To join the test, send an email to [contact@jeevagames.com](mailto:contact@jeevagames.com) with the Google account you use on your phone. You will get a link to install it from the Play Store, and updates arrive automatically.

## In a browser on your computer

Open **[editor.jeevagames.com](https://editor.jeevagames.com)** in Chrome, Edge or Firefox on a PC or laptop. Nothing to install, no account.

- With a mouse and a wide window, the editor uses a **desktop layout**: **Objects / Assets / Logic** in the left column, the 3D view in the middle, and on the right the **Inspector** of the selected object — or the **Scene settings** (sky, fog, light, variables) when nothing is selected. Event sheets and scripts open as tabs next to the 3D view. **⚙ Project settings** is in the top bar, and the **File · Edit · Scene · Help** menus beside the project name hold what the ⋮ menu holds on a phone (export, backup, scenes, shortcuts…). Change the layout under **Edit → Editor layout**.
- Right-click objects and list rows for their menu, drag files onto the window to import them, and press **?** for the keyboard shortcuts.
- Projects are saved **in that browser** on that computer. Clearing the site's data deletes them, so use [Backup](../publish/backup) to keep copies. To move a project between your phone and your computer, back it up on one and use **Import .tge** on the other.
- In the Android app, **? → Use it on your computer** shows the address and lets you send it to yourself.

## First launch

Open **Tiny Game Engine**. You land on the [home screen](./home-screen) with no projects yet. From here you can:

<Side shot="home-empty">

- **Start the tutorial** — the best way to begin: two short guided tutorials make a small game with you. See [Your first game](./first-game).
- **Choose a template** — start from one of seven ready-made games and change it. See [Templates](../templates).

Your projects are saved **on this phone** automatically as you work. There is no account and no cloud; use [Backup](../publish/backup) to keep a copy.

</Side>

:::info[Usage statistics]
On the Android app, the editor can send **anonymous** usage statistics (which screens and features are used, and errors) to help improve it. In the EU it is off until you turn it on; elsewhere it is on by default. You can switch it at any time in **? → Usage statistics**. See the [privacy policy](https://hidencod.github.io/tge-assets/privacy/).
:::
