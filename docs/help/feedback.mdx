# Help & feedback

<Art name="monster" size={90} />

Open **?** on the home screen, or **⋮ → Help & feedback** in the editor.

<Phone name="help-menu" size="small" />

| Item | What it does |
| --- | --- |
| **Send feedback** | Opens your email app with a message to the developer. Ideas, things you like, things that confused you — all welcome. |
| **Report a problem** | Same, and adds the app’s recent error log so the bug can be found. Say what you did just before it happened. |
| **Usage statistics** | (Android app) Turn anonymous statistics on or off. They show which features are used and where errors happen — never your projects. |
| **Privacy policy** | What the app keeps and sends: [read it online](https://hidencod.github.io/tge-assets/privacy/). |
| **Open-source licences** | The open-source libraries and free assets inside the app. |
| **Tiny Game Engine 1.x** | Your version and the contact address. |

Contact: [contact@jeevagames.com](mailto:contact@jeevagames.com)
