# Code scripts (JavaScript)

<Art name="tile-code" size={100} />

Most games can be made with **behaviors** and **event sheets** alone. When you want more control, write a small **JavaScript** script. Scripts and event sheets work together: they share variables, and both can find, move, create and destroy objects.

## Three kinds of script

| Kind | Where it runs | Create it |
| --- | --- | --- |
| 📜 **Object script** | On every object that has a **Code script** component with it. One copy runs per object, and gets that object as `entity`. | Logic → Code scripts → **+ New → Object script**, or Inspector → ＋ Add component → Code script → *New script…* |
| 🌍 **Game script** | Once for the whole scene. | Logic → Code scripts → **+ New → Game script** |
| 📚 **Library** | Nowhere on its own: other scripts `import` what it exports. See [Share code with libraries](#libraries). | Logic → Code scripts → **+ New → Library** |

**Properties** on the Code script component are values you can set per object in the Inspector and read in the script as `props` (e.g. a different `speed` per enemy).

## Lifecycle functions

Define any of these; the engine calls them. `function update(dt)` and `export function update(dt)` both work.

| Function | When | Object | Game |
| --- | --- | :-: | :-: |
| `start()` | Once, when the scene starts | ✔ | ✔ |
| `update(dt)` | Every frame, before physics. `dt` = seconds since the last frame | ✔ | ✔ |
| `lateUpdate(dt)` | Every frame, after physics | ✔ | |
| `onCollision(other)` | This object started touching `other` | ✔ | |
| `onCollisionEnd(other)` | This object stopped touching `other` | ✔ | |
| `onTap()` | The player tapped this object | ✔ | |
| `onClick()` | This UI button was tapped (game scripts get `onClick(button)` for every button) | ✔ | ✔ |
| `onArrived()` | This object reached the point of its `entity.moveTo()` (game scripts get `onArrived(object)` for every object) | ✔ | ✔ |
| `onDestroy()` | This object is about to be removed | ✔ | |

Variables declared at the top of a script keep their values between frames (one set per object for object scripts):

```js
let timer = 0;

function update(dt) {
  timer += dt;
  if (timer > 3) { timer = 0; game.log('3 seconds passed'); }
}
```

## What a script can use

| Name | What it is |
| --- | --- |
| `entity` | The object this script is on (object scripts). Also the type of `other` in collisions and of results from `game.find()`. |
| `game` | The running game: find/spawn/destroy objects, variables, scenes, camera, raycasts, saving. |
| `input` | Joystick (`input.axis`), buttons (`input.isDown('jump')`), touches, swipes, keys. |
| `audio` | `audio.play('Coin')`, `audio.stop()`. |
| `props` | The values set in the Inspector on the Code script component. Give defaults: `props.speed ?? 5`. |
| `vars` | A storage object for the script. |
| helpers | `lerp`, `clamp`, `random`, `randomInt`, `deg2rad` and JavaScript’s `Math`. |
| `THREE` | The [three.js](https://threejs.org/docs/) library, for advanced effects. See [three.js](#threejs). |
| `import` | Code from your [libraries](#libraries): `import { roll } from 'Dice'`. |

Full list: [Scripting API](../reference/scripting-api).

## Share code with libraries {/* #libraries */}

As a game grows, several scripts need the same code: a damage formula, a "find the nearest enemy" helper, the settings of every level. Put it in a **library** once and use it everywhere.

A library is a script whose **`export`**ed functions and values other scripts can use. It has no `start()` or `update()`.

```js
// Library named "Combat"
export const MAX_HEALTH = 100;

export function damage(target, amount) {
  const hp = (target.getVar('health') ?? MAX_HEALTH) - amount;
  target.setVar('health', Math.max(hp, 0));
  if (hp <= 0) game.destroy(target);
}

export function nearest(from, selector) {
  let best = null, bestDist = Infinity;
  for (const e of game.select(selector)) {
    const d = from.distanceTo(e);
    if (d < bestDist) { best = e; bestDist = d; }
  }
  return best;
}
```

Then, in any object script, game script or event-sheet script block, **import** it by the library's name:

```js
// Object script on a Turret
import { damage, nearest } from 'Combat';

let cooldown = 0;
function update(dt) {
  cooldown -= dt;
  const target = nearest(entity, '#enemy');
  if (target && cooldown <= 0) { damage(target, 10); cooldown = 0.5; }
}
```

Good to know:

- **Names:** `import { damage as hit } from 'Combat'` renames; `import * as Combat from 'Combat'` (or `import Combat from 'Combat'`) gives the whole library, used as `Combat.damage(…)`.
- **One copy:** a library runs **once per game**, the first time something imports it. Its top-level variables are shared by every script that imports it, and keep their values when the scene changes, so a library is also a good place for game-wide state.
- **Libraries can import libraries**, but not in a circle (A imports B imports A).
- Libraries get `game`, `input`, `audio`, `THREE` and the helpers, like a game script; there is no `entity` or `props`.
- If the name is wrong, the error lists the libraries that do exist, with the line of the `import`.

## Talk to other scripts and components {/* #components */}

A library is shared by the whole game. When the code belongs to **one object** (this enemy's health, this door's open/close), put it in that object's script and **`export`** what other scripts may use:

```js
// Object script named "Enemy"
export let hp = 3;

export function hit(amount) {
  hp -= amount;
  if (hp <= 0) entity.destroy();
}
```

Any other script reaches it with **`getScript('Name')`** on that object:

```js
// Object script on a Bullet
function onCollision(other) {
  other.getScript('Enemy')?.hit(1);   // ?. : does nothing if `other` has no Enemy script
  entity.destroy();
}
```

- Each object has **its own copy**: hitting one enemy doesn't change the others' `hp`.
- Values are live: `getScript('Enemy').hp` is always the current value.
- `getScript()` gives `null` when the object has no script of that name (upper/lower case doesn't matter). It works on `entity` too, to reach another script on the same object.
- Only what is exported can be used; `start`, `update` and the other lifecycle functions stay private.

To **read a component's settings**, use `getComponent()`. It works for components and behaviors:

```js
const mass = entity.getComponent('rigidbody').mass;
const maxHp = other.getComponent('health')?.maxHealth;
if (other.hasComponent('car')) { /* … */ }
```

`getComponent()` gives a **copy**: changing it does nothing. To change things, use the methods for them, such as `setBehaviorParam('health', 'maxHealth', 5)`, `setColor()` or `setVelocity()` (see the [Scripting API](../reference/scripting-api)).

## three.js (advanced) {/* #threejs */}

The engine draws everything with [three.js](https://threejs.org/docs/), and scripts can use it directly when the built-in components are not enough: custom materials and shaders, generated meshes, extra lights, instancing.

- **`THREE`** is the three.js library, in every script. (`import * as THREE from 'three'` also works, so code from three.js examples can be pasted as it is.)
- **`entity.object3d`** is the three.js object of an object.
- **`game.three`** has the `renderer`, the current `scene` and the `camera` drawing this frame.

```js
// Game script: a glowing ring that pulses, built with three.js
let ring;
function start() {
  ring = new THREE.Mesh(
    new THREE.TorusGeometry(3, 0.15, 12, 64),
    new THREE.MeshStandardMaterial({ color: '#4fc3ff', emissive: '#1a6fff', emissiveIntensity: 2 }),
  );
  ring.rotation.x = Math.PI / 2;
  ring.position.set(0, 0.2, 0);
  game.three.scene.add(ring);
}
function update(dt) {
  ring.scale.setScalar(1 + Math.sin(game.time * 3) * 0.1);
}
```

```js
// Object script: give this object a custom shader material
function start() {
  const mat = new THREE.ShaderMaterial({
    uniforms: { time: { value: 0 } },
    vertexShader: 'varying vec3 vPos; void main() { vPos = position; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }',
    fragmentShader: 'uniform float time; varying vec3 vPos; void main() { gl_FragColor = vec4(0.5 + 0.5 * sin(vPos.y * 4.0 + time * 3.0), 0.3, 0.8, 1.0); }',
  });
  entity.object3d.traverse((o) => { if (o.isMesh) o.material = mat; });
  this.mat = mat;
}
function update(dt) { this.mat.uniforms.time.value += dt; }
```

Objects you add yourself are not part of the scene in the editor: they exist only while the game runs, they have no physics, and events don't see them. Remove what you add when you no longer need it. The engine still owns the renderer and camera; changing their settings can affect how the game looks everywhere.

## Units and conventions

- Distances in meters; **+Y is up**; an object’s **forward is −Z**.
- Angles in **degrees** (`entity.rotation.y = 90`).
- Multiply speeds by `dt` so the game runs the same on slow and fast phones.
- Colors are CSS hex strings: `"#ff8800"`.

## Examples

### Move with the joystick

```js
function update(dt) {
  const speed = props.speed ?? 5;
  entity.translate(input.axis.x * speed * dt, 0, -input.axis.y * speed * dt);
  if (input.axis.x || input.axis.y) {
    entity.rotation.y = Math.atan2(-input.axis.x, input.axis.y) * 180 / Math.PI;
  }
}
```

### Jump (needs a Physics body and a Collider)

```js
function update(dt) {
  if (input.wasPressed('jump') && entity.isOnGround()) {
    const v = entity.getVelocity();
    entity.setVelocity(v.x, 7, v.z);
  }
}
```

### Collect coins

```js
function onCollision(other) {
  if (other.hasTag('coin')) {
    other.destroy();
    game.setVar('Score', Number(game.getVar('Score') ?? 0) + 1);
    audio.play('Coin');
  }
}
```

### Enemy follows the player

```js
function update(dt) {
  const player = game.find('Player');
  if (!player) return;
  const p = player.getWorldPosition();
  entity.lookAt(p.x, entity.position.y, p.z);
  if (entity.distanceTo(player) > 1.5) entity.moveToward(p.x, entity.position.y, p.z, 2 * dt);
}
```

### Spawner (game script)

```js
let timer = 0;
function update(dt) {
  timer += dt;
  if (timer >= 1) {
    timer = 0;
    game.spawn('Coin', { x: random(-5, 5), y: 6, z: random(-5, 5) });
  }
}
```

### Tap to change color

```js
const colors = ['#ff5c6c', '#ffb547', '#3ecf8e', '#4f8cff'];
let i = 0;
function onTap() {
  i = (i + 1) % colors.length;
  entity.setColor(colors[i]);
}
```

### Walk to points (Move to position)

`entity.moveTo(x, z, speed?)` walks to a point on the ground, going around walls; `onArrived()` runs when it gets there. Give the object a **Physics body** (dynamic, **Fixed rotation** on) and a **Collider** so it walks up and down terrain. Without a body it moves in a flat line at its own height.

```js
// A guard walks around a square, forever
const points = [[0, 0], [8, 0], [8, 8], [0, 8]];
let i = 0;

function start() {
  entity.moveTo(points[0][0], points[0][1], 3);
}

function onArrived() {
  i = (i + 1) % points.length;
  entity.moveTo(points[i][0], points[i][1], 3);
}
```

Tap to move: `const p = game.touchWorld(); entity.moveTo(p.x, p.z);` inside `if (input.tapped)` in `update`. `entity.stopMoving()` cancels, and `entity.movingTo` is true while it walks.

### UI: pause button

```js
// Object script on the PauseButton
function onClick() {
  game.find('PauseScreen').visible = true;
  game.pause();
}
```

```js
// On a HealthBar (progress bar)
entity.setUIValue(entity.getUIValue() - 10);
entity.setText('HP');
entity.setUIColors({ background: '#222', text: '#fff', fill: '#ff5c6c' });
```
