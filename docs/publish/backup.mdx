# Backup & move projects

<Art name="cube-stone" size={90} />

Projects are saved inside the app (or the browser), on your device. A **backup** is a single `.tge` file with everything — scenes, events, scripts and assets.

## Where projects are kept

- **Android app:** besides the app's own storage, the app keeps a copy of every project in the phone's **Documents/TinyGameEngine** folder, as a `.tge` file. It is written a couple of minutes after you change something, and right away when you close the project or switch to another app. Uninstalling the app or clearing its data deletes the app's own storage, but not this folder: reinstall, tap **Import .tge** and pick the file from that folder. Android 10 and older ask once for permission to use the folder.
- **Web editor:** projects are in the browser's storage for this site. Clearing the browser's data for the site deletes them. The editor asks the browser to keep them for good; if the browser won't promise that, the home screen shows **Browser storage can be cleared**. Installing the editor as an app (**Install app**) usually makes the browser keep them, and Safari clears a site not used for 7 days unless it is installed. Either way, back up the projects you care about.
- The web editor and the Android app don't share projects: move one with a backup or [GitHub sync](./github-sync).

A project changed more than a week ago that has not been backed up since gets an orange **No backup** (or **Backup 9 days ago**) tag on the home screen. Tap the tag to back it up. A `.tge` backup, the Android app's copy and a push to GitHub all count as a backup.

## Make a backup

Either:

- In the editor: **⋮ → Backup project (.tge)**, or
- On the home screen: **⋮** on the project → **Backup (.tge)**.

The share sheet opens: save it to Files or Google Drive, or send it to yourself.

## Restore or move to another phone

On the home screen tap **⬇ Import .tge** and choose the file. It is added as a **new project** — it never replaces an existing one, so importing twice gives you two copies.

## Share a project with a friend

Send them the `.tge` file. They import it and can open, play and change your project — a great way to learn from each other or work on a game together.

## Project as a folder (for git and syncing)

**⋮ → Project as folder (.zip)** saves the same project as a zip of **many small text files** instead of one `.tge`. Unzip it and you can read it, compare two versions, or put it in a git repository.

| File | Holds |
| --- | --- |
| `project.json` | name, settings, global variables, start scene, and the order of everything else |
| `scenes/`, `sheets/`, `prefabs/`, `timelines/`, `tables/`, `animators/`, `materials/` | one file for each |
| `scripts/` | each script as a `.json` with its settings and a `.ts` file with its code |
| `shaders/` | each shader as a `.json` plus `.vert.glsl` and `.frag.glsl` |
| `localization.json`, `services.json` | the texts and the achievements, boards and products |
| `assets/index.json` and `assets/files/` | the list of images, sounds and models, and the files themselves |

The same project always makes the same files, so a change to one scene changes one file. Import the zip with **Import .tge** like any backup: it comes back as a new project.

:::tip[Good habits]
- Back up before big changes, or use **Duplicate** on the home screen to keep a copy.
- Keep backups outside the phone (Drive, email).
- Also back up your [APK signing key](./export-apk#signing-key) once.
:::
