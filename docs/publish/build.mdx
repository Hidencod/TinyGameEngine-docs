# Build

<Art name="flag-small" size={85} />

**☰ → Build** (on a computer **File → Build…**, `Ctrl+Shift+B`) turns your project into a game you can share. Pick a platform, choose the scenes that go in, and tap **Build**.

<Side shot="build-web">

| Part | What it does |
| --- | --- |
| **Web / Android / Windows** | The platform. Your choice is remembered with the project. |
| **Start scene** | The scene the game opens with. It is the same start scene **Run project** uses. |
| **Scenes in build** | One checkbox per scene. Untick a scene to leave it out of the game, for example a test level. The start scene always goes in. |
| **Settings** | The options of the chosen platform. |

</Side>

2 seconds) before their own loading screen. With Pro they go straight in.

## AI credits

When the AI assistant's allowance runs out (Free: each day; Pro: each month), **credits** keep it going. They also let a Free
account use the Claude models. Every account starts with **50**; they never expire.

- The coin in the AI assistant panel shows your balance; tap it to buy more. **Home → Profile → AI credits** does the
  same and has the history.
- A new game from a starter kit uses about **20 credits**, a small change 1 to 5; the Claude models use more. Each
  request shows what it used under the reply.
- Packs: **500** for US$4.99, **1,200** for US$9.99, **3,000** for US$19.99 (in the Android app, Google Play's price
  in your currency). Unspent packs can be refunded within 14 days: see the
  [refund policy](https://jeevagames.com/engine/refunds).

## Web

Makes a game that runs in any browser. **Output** has two choices:

- **Single file (.html)** — one file with everything inside. It plays offline, even from a double-click. See [Web build](./export-html).
- **Folder (.zip)** — a page plus separate files, for web hosts and **itch.io**. See [Web build](./export-html#folder).

## Android

Makes a signed **APK** on your phone, or an **App Bundle** for Google Play, with your own app name, package, version,
icon, orientation and [keystore](./export-apk#signing-key). See [Android build](./export-apk).

## Windows {/* #windows */}

Makes one **.exe** that runs your game in its own window on Windows 10 and 11. There is no installer and no other
file to send: share the .exe or upload it to **itch.io**. Needs **Pro**.

| Setting | What it does |
| --- | --- |
| **Window** | The window's size when the game opens (1280 × 720 unless you pick another). |
| **Fullscreen** | Start fullscreen instead of in a window. |
| **Resizable** | Let players resize the window. The game fits itself as it does in a browser. |
| **App icon** | The icon in Explorer, the title bar and the taskbar. It is the same picture as the Android app icon. |

- Players switch fullscreen with **F11** or **Alt+Enter**. The **Enter fullscreen** and **Exit fullscreen** actions
  fill the whole screen too.
- A **Quit** button: the **Quit game** action (System), or `game.quit()` in a script, closes the window. In the
  editor it stops the play-test.
- Saves ([save slots](../logic/variables#save-slots), `localStorage`) stay on the player's PC in
  `%APPDATA%\<game name>-<id>`. They survive new versions of the game as long as it is the same project.
- The game runs on **Microsoft Edge WebView2**, which comes with Windows 10 and 11. On the rare PC without it, the game
  says so and links to the download.
- The .exe is not code-signed, so the first time someone runs it Windows may show *Windows protected your PC*. They
  click **More info → Run anyway**. Games on itch.io are often shared this way.

## While it builds

A panel shows the steps (*Player*, *Scripts*, *Files 3 / 19*, *Packing*, …). If your project has [saved tests](../editor/tests), they run first and the build stops if one fails. When it is done, a message shows the size of the game and the file is saved or shared.

## Publish is separate

**☰ → Publish game (link)** puts the game online with a link and does not use the Build panel. See [Publish a link](./publish-link).
