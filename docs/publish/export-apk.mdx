# Android build

<Art name="tile-gamepad" size={100} />

In the [Build panel](./build) (**☰ → Build**) choose **Android**. It turns your game into a real **Android app** — built and signed **on your phone**, no PC and no internet needed. Install it, share it with friends, or put it on sites like itch.io.

## Settings

<Side shot="apk-dialog">

Android builds need you to be [signed in](./build#accounts). Fill in the **Settings** and tap **Build**:

| Field | What it does |
| --- | --- |
| **Format** | **APK** — install it directly or share it. **App Bundle (.aab)** — for [Google Play](#google-play) (Pro). |
| **Account** | Your Google account and plan (**Free** or **Pro**), **Upgrade** (opens [Pro](#pro)) or **Manage**, **Sign out**. |
| **App name** | Shown under the icon on the home screen. |
| **Package name** | The app’s unique id, like `com.yourname.coinhunt`. **Keep it the same** so a new export installs as an **update**; changing it makes a separate app. **Use default** restores the suggested one. |
| **Version** | Shown in Android settings (1.0, 1.1…). The internal build number goes up automatically, so every export can be installed over the previous one. |
| **App icon** | An image from your assets. A square image works best; it is used for the normal, round and adaptive icons. |
| **Screen orientation** | Landscape, Portrait or Any. |
| **Keystore** | Which key signs the app: **Editor key** or a keystore you imported. See [Signing key](#signing-key). |

Your choices are remembered for the next export.

</Side>

After a few seconds the **share sheet** opens with the `.apk` file: save it, or send it to another phone.

## Install the APK

1. Open the `.apk` file on an Android phone (from Files, Drive, or the chat you sent it in).
2. Android asks to allow installing apps from that source the first time — allow it.
3. Tap **Install**. Your game appears on the home screen with its icon.

## Signing key {/* #signing-key */}

Android only installs apps that are **signed**. An update installs over an older version **only if it has the same package name and the same key**. **Keystore** chooses the key, per project:

- **Editor key** — Tiny Game Engine makes one the first time you build and keeps it on this device.
- **Import keystore…** — your own `.jks`, `.keystore`, `.p12` or `.pfx` file, for example the **upload key** you
  made in Android Studio or with `keytool`. Pick the file and type its password (and the key password, if it has its
  own). The key is kept on this device; the project only remembers which key it uses, so on another device import
  the same file again. **Remove** takes it off this device (the file itself is not changed). Only RSA keys work.

<Side shot="build-keystore">

Under the choice you see the key's **SHA-1** and **SHA-256** fingerprints with **Copy** buttons — Google Play Console
and Google Cloud ask for them.

</Side>

:::warning[Back up your key]
If you reinstall Tiny Game Engine, switch phones or clear its data, the key is gone and your next APK can’t update the old one (players would have to uninstall first). Back it up once:
:::

**Key…** (next to **Editor key**):

| Item | What it does |
| --- | --- |
| **Back up key (.tgekey)** | Saves the key as a file protected by a **password** you choose. Keep it somewhere safe (Drive, email to yourself). |
| **Restore key** | Loads a `.tgekey` backup (needs its password) — on a new phone or after reinstalling. |

The menu shows your key’s short fingerprint, so you can check two phones use the same key.

## Google Play {/* #google-play */}

APKs are for sharing and installing directly. Google Play needs an **App Bundle (.aab)**: set **Format** to
**App Bundle**. App Bundles are part of **Pro** (a monthly or yearly subscription under **Account**); the bundle is
made out to your app on our server and signed **on your device** with your keystore — your key never leaves it.

<Side shot="build-account">

**Account** shows your Google account and plan. **Upgrade** opens the Pro page; **Manage** (Pro) changes or cancels the
subscription.

</Side>

### Pro {/* #pro */}

<Side shot="paywall">

**Build** with **App Bundle** on a Free account opens the Pro page (also **Account → Upgrade**, and **Home → your
email → Upgrade to Pro**). Pick **Monthly** ($4) or **Yearly** ($29, about 40% less), then **Upgrade to Pro**:

- **On the web** the checkout opens in a new tab. Pay there and come back: the page notices the payment by itself,
  shows **You're Pro**, and **Continue** carries on with the build.
- **In the Android app** Google Play's purchase sheet opens.

Cancel any time; Pro lasts until the end of the period you paid for. A full refund within 14 days of the first
payment — see [prices, terms and refunds](https://jeevagames.com/engine).

</Side>

1. Import your Play **upload key** under **Keystore** (or use the editor key and back it up — Play needs every update
   signed with the same upload key).
2. **Build** and upload the `.aab` in Play Console (**Test and release → Production / Testing → Create new release**).
3. Keep the **Package name** the same for every update; the version number goes up by itself.
