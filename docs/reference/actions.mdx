# Actions

<Art name="block-add" size={200} />

Actions are the **DO** part of an event. They run from top to bottom when the event’s conditions are true. Actions on an object apply to the instances the conditions **picked** (or to all instances of that object if none were picked). See [How events work](../logic/event-sheets).

:::tip[Every value is an expression]
Number and text fields accept expressions, e.g. `Score + 1`, `"Score: " + Score`, `Player.x`, `random(1, 6)`. See [Expressions](./expressions).
:::

There are **89 actions**, grouped by category as in the action picker.
