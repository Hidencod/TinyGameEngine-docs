# Behaviors reference

<Art name="penguin" size={85} />

Settings are shown in the Inspector with friendly names; scripts and the *Set behavior setting* action use the **id**. For explanations and screenshots see the [Behaviors guide](../behaviors).

<BehaviorTable />

## Using behaviors from events and scripts

| To… | Event | Script |
| --- | --- | --- |
| Turn on/off | *Enable/disable behavior* | `entity.setBehaviorEnabled('car', false)` |
| Change a setting | *Set behavior setting* | `entity.setBehaviorParam('platformer', 'speed', 8)` |
| Read a setting | `Player.behavior("platformer", "speed")` | `entity.getBehaviorParam('platformer', 'speed')` |
