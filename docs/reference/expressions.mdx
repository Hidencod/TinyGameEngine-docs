# Expressions

<Art name="block-collide" size={200} />

Every number or text field in an event is an **expression**: a small formula the game works out while it runs. Type `10`, `Score + 1`, `"Score: " + Score`, `Player.x` or `random(1, 6)`.

## Values and operators

| Write | Meaning |
| --- | --- |
| `12`, `3.5`, `-1` | Numbers |
| `"text"` or `'text'` | Text (with quotes) |
| `true`, `false` | Yes / no |
| `+ - * / %` , `^`, `mod` | Math. `+` joins text when either side is text: `"Lives: " + Lives` |
| `= <> != ≠ < <= ≤ > >= ≥` | Compare (gives true/false) |
| `and or not` (also `& \| !`) | Logic |
| `cond ? a : b` | Pick a or b |
| `Score` | A global, scene or local variable, by name |
| `Player.x` | A property of an object (see below) |
| `Enemy.hp` | An instance variable (also `Enemy.var("hp")`) |

:::note[Mistakes don’t crash the game]
If you mistype a name, the game keeps running: it shows a friendly message once and the unknown value counts as `0`. The event with the problem gets a red badge in the editor.
:::

## Functions

### Random

| Function | What it does |
| --- | --- |
| `random(min, max)` | Random decimal number between min and max |
| `randomInt(min, max)` | Random whole number from min to max (inclusive) |
| `choose(a, b, ...)` | Picks one of the values at random |

### Game

| Function | What it does |
| --- | --- |
| `loopindex("i")` | Current number of the loop called "i" (For loop), or of the innermost loop without a name |
| `time` | Seconds since the scene started |
| `dt` | Seconds since the last frame (multiply speeds by dt) |
| `fps` | Frames per second |
| `loopIndex` | Current number of the innermost loop (Repeat, For, For each, While) |
| `screenWidth` | Screen width in pixels |
| `screenHeight` | Screen height in pixels |

| --- | --- |

| `max(a, b, ...)` | Largest value |

| `ceil(x)` | Round up |

## Object properties

Write the object’s name (or `Self` inside an action on that object), a dot, then the property: `Player.x`, `Coin.count`, `Self.angle`.

| Property | What it gives |
| --- | --- |
| `.x` | X position |
| `.y` | Y position (height) |
| `.z` | Z position |
| `.angle` | Turn angle around Y (degrees) |
| `.rotX` | Rotation X (degrees) |
| `.rotY` | Rotation Y (degrees) |
| `.rotZ` | Rotation Z (degrees) |
| `.scaleX` | Scale X |
| `.scaleY` | Scale Y |
| `.scaleZ` | Scale Z |
| `.vx` | Velocity X |
| `.vy` | Velocity Y |
| `.vz` | Velocity Z |
| `.speed` | Speed (length of velocity) |
| `.count` | Number of these objects in the scene |
| `.pickedCount` | Number of picked instances in this event |
| `.worldX` | World X position |
| `.worldY` | World Y position |
| `.worldZ` | World Z position |
| `.text` | Text shown (text objects) |
| `.visible` | true if visible |
| `.name` | Object name |
| `.id` | Unique id of the instance |
| `.value` | Progress bar value (UI) |
| `.max` | Progress bar maximum (UI) |
| `.pressed` | UI button is held down |

Inside an action on an object type, `Coin.x` means *the coin being processed*. With several picked coins, the action runs once per coin and each sees its own values.
