# Scripting API

<Art name="tile-code" size={95} />

This is the complete list of what code scripts can use. It is the same list the code editor’s autocomplete and **API** help sheet show. For an introduction, read [Code scripts](../logic/scripting).

## Lifecycle functions

Define any of these in a script; the engine calls them.

| Function | When it runs | Object script | Game script |
| --- | --- | :-: | :-: |
| `start()` | Called once when the scene starts. | ✔ | ✔ |
| `update(dt)` | Called every frame. dt = seconds since last frame. | ✔ | ✔ |
| `lateUpdate(dt)` | Called every frame after physics. | ✔ |  |
| `fixedUpdate(dt)` | Called on every physics step (60 a second), whatever the frame rate. dt is always 1/60. | ✔ | ✔ |
| `onEnable()` | The object is switched on: before start(), and each time it is enabled again. | ✔ | ✔ |
| `onDisable()` | The object is switched off or about to be destroyed. | ✔ | ✔ |
| `onTriggerEnter(other, collision)` | This entity entered, or was entered by, a trigger `other`. | ✔ |  |
| `onTriggerStay(other, collision)` | Every frame while it overlaps a trigger `other`. | ✔ |  |
| `onTriggerExit(other, collision)` | This entity left a trigger `other`. | ✔ |  |
| `onCollision(other, collision)` | This entity started touching `other`. collision has the details: contacts, point, normal, impulse, relativeVelocity, speed, isTrigger. | ✔ |  |
| `onCollisionStay(other, collision)` | Every frame while it touches `other` (only define it if you need it: it reads every contact). | ✔ |  |
| `onCollisionEnd(other, collision)` | This entity stopped touching `other`. | ✔ |  |
| `onParticleCollision(other, events)` | Particles hit `other` (Collision module with Send Collision Messages). Called on the system's object and on the one hit. events: [&#123; intersection, normal, velocity, other &#125;]. | ✔ |  |
| `onParticleTrigger(events)` | Particles met the Triggers module's colliders (actions set to Callback). events: [&#123; type: "inside" \| "outside" \| "enter" \| "exit", particles &#125;]. | ✔ |  |
| `onParticleSystemStopped()` | Its Particle System stopped and the last particle died (Stop Action: Callback). | ✔ |  |
| `onTap()` | The player tapped this entity. | ✔ |  |
| `onClick()` | This UI button was clicked. | ✔ |  |
| `onPointerDown(event)` | The player pressed this UI element (needs Raycast Target). event: &#123; x, y, entity &#125;. | ✔ |  |
| `onPointerUp(event)` | The player let go of this UI element without dragging it. | ✔ |  |
| `onPointerEnter(event)` | A mouse moved onto this UI element (touch screens have no hover). | ✔ |  |
| `onPointerExit(event)` | A mouse moved off this UI element. | ✔ |  |
| `onLongPress(event)` | The player held this UI element for half a second without moving. | ✔ |  |
| `onBeginDrag(event)` | The player started dragging this UI element (moved more than a few pixels). | ✔ |  |
| `onDrag(event)` | Every move while dragging. event.delta = [dx, dy] since the last one, in the element's reference px with Y up: add it to component('ui').anchoredPosition to follow the finger. | ✔ |  |
| `onEndDrag(event)` | The player let go after dragging this UI element. | ✔ |  |
| `onDrop(event)` | Something was dropped on this UI element. event.dragged is the element that was dragged; event.entity is this one. | ✔ |  |
| `onArrived()` | It reached the point of entity.moveTo() (or got as close as it could). | ✔ |  |
| `onCurveEnd()` | This entity (with Follow curve) reached the end of its curve: each time round when it loops, each end when it ping-pongs. | ✔ |  |
| `onDestroy()` | This entity is about to be destroyed. | ✔ |  |

## `entity` — entity {/* #entity */}

The entity the script is attached to (also `other` in collisions, and results of game.find()).

| Member | Type | Description |
| --- | --- | --- |
| `id` | `string` | Unique id of this entity. |
| `name` | `string` | Object type name (clones share it), e.g. "Coin". |
| `tags` | `Set` | Tags of this entity (read-only set). Use hasTag/addTag. |
| `layer` | `string` | The layer the object is on ("Default" unless changed; Project settings → Layers). Writable: entity.layer = "Water". Cameras with a target texture can leave layers out; game.raycast takes layers. |
| `persist` | `boolean` | True: the object stays when the game goes to another scene (with its children, position and variables) instead of being made again. | `destroyed` | `boolean` | True once the entity has been destroyed. |

| `rotation` | `{x,y,z}` | Local rotation in DEGREES. Writable: entity.rotation.y += 90 * dt |
| `scale` | `{x,y,z}` | Local scale. Writable: entity.scale.x = 2 |
| `visible` | `boolean` | Show / hide the entity. |

| `applyForce(x, y, z)` | `void` | Continuous push (call every frame). |
| `isOnGround()` | `boolean` | True if a dynamic body rests on something. |
| `setColor(hex)` | `void` | Change material color, e.g. setColor("#ff0000") |
| `setOpacity(0..1)` | `void` | Change material opacity. |

| `setUIColors({ background, text, fill })` | `void` | Change UI colors, e.g. &#123; background: "#ff0000" &#125;. |
| `setUIInteractable(on)` | `void` | Grey a button or slider out, or turn it back on (Interactable). |
| `getUIPosition()` | `{x, y}` | Where a UI element sits: its anchored position in canvas pixels from its anchor. |
| `setUIPosition(x, y)` | `void` | Move a UI element to this anchored position (canvas px). Leave an axis out (undefined) to keep it. |
| `isUI()` | `boolean` | Is this object a UI element (has a Rect Transform)? |

| `animator` | `Animator\|null` | The Animator (an Animator component with a controller), as in Unity: animator.setFloat("Speed", 3), setBool, setInteger, setTrigger("Attack"), resetTrigger, getFloat / getBool / getInteger, play("Die"), crossFade("Run", 0.2), state, isInState("Jump"), normalizedTime(), isInTransition(), setLayerWeight(1, 0.5), speed. | `isAnimationBusy()` | `boolean` | True while a play-once animation (loop off) is still running. |
| `getAnimationNames()` | `string[]` | All clip names of the model, or the animations of a sprite. |

| `tween(property, to, seconds, ease?)` | `void` | Animate 'x' \| 'y' \| 'z' \| 'angle' \| 'size' \| 'opacity' to a value, e.g. tween('size', 1.5, 0.3, 'back'). Eases: linear, easeIn, easeOut, easeInOut, back, elastic, bounce. |
| `isTweening(property?)` | `boolean` | A tween is running (of that property, or any). |
| `stopTweens()` | `void` | Stop all tweens where they are. |

### Move with joystick

```js
// Move with the joystick and face the walking direction.
export let speed = 5;   // meters per second, set per object in the Inspector

function update(dt) {
  const x = input.axis.x;
  const y = input.axis.y;
  entity.translate(x * speed * dt, 0, -y * speed * dt);
  if (x !== 0 || y !== 0) {
    entity.rotation.y = Math.atan2(-x, y) * 180 / Math.PI;
  }
}
```

### Follow the player

Chase the entity named "Player" and stop when close.

```js
// Chase the Player.
export let speed = 2;

function update(dt) {
  const player = game.find('Player');
  if (!player) return;
  const target = player.getWorldPosition();
  entity.lookAt(target.x, entity.position.y, target.z);
  if (entity.distanceTo(player) > 1.5) {
    entity.moveToward(target.x, entity.position.y, target.z, speed * dt);
```

### Patrol between two points

Walk back and forth between two objects you pick in the Inspector (each enemy its own).

```js
// Walk back and forth between two objects picked in the Inspector.
// Put this script on any number of enemies and give each its own Point A and Point B
// (empty objects make good markers). The fields below show up in the Inspector.
export let speed = 2;               // meters per second
export let pointA = field.object(); // pick an object in the Inspector
export let pointB = field.object();
export let pause = 0.5;             // seconds to wait at each end

let goingToB = true;
let waitLeft = 0;

function update(dt) {
  const target = goingToB ? pointB : pointA;
  if (!target) return;                       // not picked yet
  if (waitLeft > 0) { waitLeft -= dt; return; }
  const me = entity.getWorldPosition();
  const p = target.getWorldPosition();
  entity.lookAt(p.x, me.y, p.z);             // face it, staying upright
  entity.moveToward(p.x, me.y, p.z, speed * dt);
  if (Math.hypot(p.x - me.x, p.z - me.z) < 0.2) {
    goingToB = !goingToB;                    // turn around
    waitLeft = pause;
  }
}
```

```js
  if (input.swipe === 'left') lane = clamp(lane - 1, -1, 1);
  if (input.swipe === 'right') lane = clamp(lane + 1, -1, 1);
  if (input.swipe === 'up' && entity.isOnGround()) entity.applyImpulse(0, 6, 0);
  entity.position.x = lerp(entity.position.x, lane * 2, 10 * dt);
}
```

### Get in and out of a vehicle

Put on the Player. Press the "use" button next to a boat or car (tag #vehicle) to get in or out. Seating and the camera are automatic; steering is yours.

```js
// Put this on the Player. Give the vehicle the tag "vehicle" and a Car or Boat behavior, and add
// a control button called "use" in Scene → Controls.
function update(dt) {
  const vehicle = entity.vehicle;

  if (input.wasPressed('use')) {
    if (vehicle) {
      entity.exitVehicle();   // put down beside it, walking again, camera back on you
    } else {
      // Get in: the nearest vehicle within 3 meters.
      let nearest = null;
      for (const v of game.select('#vehicle')) {
        if (entity.distanceTo(v) < 3 && (!nearest || entity.distanceTo(v) < entity.distanceTo(nearest))) nearest = v;
      }
      if (nearest) entity.enterVehicle(nearest);   // sits in the seat, camera follows
    }
    return;
  }

  // Entering does not steer: pass the joystick to whoever you are driving.
  if (vehicle) {
    if (vehicle.behavior('car')) vehicle.driveCar(input.axis.x, Math.max(input.axis.y, 0), Math.max(-input.axis.y, 0));
    else vehicle.setMoveInput(input.axis.x, input.axis.y);
  } else {
    entity.setMoveInput(input.axis.x, input.axis.y);
  }
}
```
