# Physics

<Art name="rock" size={105} />

Tiny Game Engine uses the **Rapier** physics engine. Two components work together:

- a **Collider** gives an object a shape to touch things with;
- a **Physics body** makes it part of the physics world: gravity, mass, friction, bouncing.

Shapes added from the ＋ Add menu already have a Collider. A new scene’s Ground has a **static** Physics body, so things can stand on it.

## Collider

<Side shot="card-collider" crop>

| Field | What it does |
| --- | --- |
| **Shape** | The collision shape (see below). |
| **Size / Radius / Height** | For box, sphere and capsule shapes (before the object’s scale). |
| **Offset** | Moves the shape relative to the object. |
| **Trigger only** | Detects touches, but things pass through: coins, checkpoints, finish lines, danger zones. |
| **One-way platform** | For a static object: things stand on it from above and jump **up through it from below**, like a platform in a 2D game. A character can also drop down through it (press **Down** and jump with a Platformer in *Side view*). |

</Side>

### Collider shapes {/* #collider-shapes */}

<Row>
  <Crop name="card-collider-box" caption="Box" width={300} />
  <Crop name="card-collider-sphere" caption="Sphere" width={300} />
  <Crop name="card-collider-capsule" caption="Capsule" width={300} />
</Row>

| Shape | Use for |
| --- | --- |
| **Automatic (from shape)** | The default. Follows the visible shape and scale. Models follow their real shape (still objects: exact; moving objects: convex parts). |
| **Box** | Crates, walls, platforms. |
| **Sphere** | Balls, round pickups. |
| **Capsule** | Characters — slides smoothly over steps and bumps. |
| **Convex hull (models)** | One shrink-wrapped hull around a model. Fast; fills in gaps and dents. |
| **Exact mesh (models)** | Follows every triangle. Best for still scenery: trees, arches, ramps, race tracks. |

Turn on **Gizmos → Colliders** in the viewport toolbar (or **Colliders** in Play mode) to see them.

## Physics body

<Row>
  <Crop name="card-rigidbody-dynamic" caption="Dynamic" width={300} />
  <Crop name="card-rigidbody-static" caption="Static" width={300} />
  <Crop name="card-rigidbody-kinematic" caption="Kinematic" width={300} />
</Row>

| Type | Behaves like… |
| --- | --- |
| **Dynamic (falls, gets pushed)** | A real object: gravity, collisions, forces. Players, balls, crates, cars. |
| **Static (never moves)** | Ground, walls, buildings. Cheapest. |
| **Kinematic (moved by logic)** | Moving platforms, doors, elevators: moved by events/behaviors/tweens, pushes dynamic objects but isn’t pushed. |

| Field | What it does |
| --- | --- |
| **Mass** | (Dynamic) Heavier objects push lighter ones. |
| **Friction** | 0 = ice, 1 = rubber. |
| **Bounciness** | 0 = no bounce, 1 = bounces back fully. |
| **Gravity scale** | (Dynamic) 1 = normal, 0 = floats, 2 = falls fast, negative = rises. |
| **Don’t tip over** | (Dynamic) Keeps it upright — for characters. |
| **Air drag / Spin drag** | (Dynamic) Slows moving / spinning over time. |
| **Freeze X / Y / Z** | (Dynamic) The body cannot move along that axis, like Unity's Freeze Position. Freeze **Z** to keep a body in one plane for a [2D game](./2d-games). |

The world’s gravity is set in [Project settings](../editor/project-settings) (Earth: 0, −9.82, 0).

## Collisions in events

| Condition | True when… |
| --- | --- |
| ⚡ **On collision with** | the object *starts* touching another (once per touch). |
| ⚡ **On collision ended** | it stops touching. |
| **Is touching** | it is touching right now (every frame). |
| **Is on ground** | it stands on something. |
| **Has line of sight to** | nothing solid is between it and another object. |
| **Raycast** / **Raycast from** | an invisible ray hits something solid (see [Raycasts](#raycasts)). |

Actions: **Set velocity**, **Push (impulse)** (a kick), **Apply force** (a push over time), **Jump**. In scripts: `entity.applyImpulse(0, 5, 0)`, `game.raycast(from, to)` (see [Raycasts](#raycasts)). See the [Conditions](../reference/conditions#physics) and [Actions](../reference/actions#physics) reference.

:::caution[Common problems]
- **Falls through the floor** — the floor needs a Collider (and a static body); very fast small objects may need a bigger collider.
- **Doesn’t move** — a behavior like Platformer or Car needs a **dynamic** body.
- **Rolls over / tips** — tick **Don’t tip over**.
- **Coins block the player** — tick **Trigger only** on the coin’s collider.
:::

## Raycasts

A raycast shoots an invisible ray and tells you what it hit first. Use it for a gun that hits what it aims at, a character that checks the ground or a wall ahead, or an enemy that looks for the player. Triggers (coins, checkpoints) never block a ray.

Two conditions in the **Physics** group:

| Condition | The ray starts… |
| --- | --- |
| **Raycast from** (on an object) | at the object, going **forward, backward, left, right, up or down**. **Start height** lifts it, for example to eye level. It never hits the object itself. |
| **Raycast** (no object) | at any point (X, Y, Z) and goes in any direction (X, Y, Z), for **Length** meters. |

Both have three optional filters: **Must hit** (true only when the ray hits that kind of object, and it becomes the picked object for the actions), **Only tag** (ignore everything without that tag) and **Ignore** (objects the ray passes through).

When the condition is true, the actions of the same event can read what was hit:

| Value | Meaning |
| --- | --- |
| `rayhitname()` | the name of the object that was hit |
| `rayHitX`, `rayHitY`, `rayHitZ` | where it hit |
| `rayNormalX`, `rayNormalY`, `rayNormalZ` | which way the surface faces (`rayNormalY` is 1 on flat ground) |
| `rayDistance` | how far the ray travelled, in meters |

In scripts, the same thing is `game.raycast(from, to)` or, along a direction:

```js
const hit = game.raycast(entity.position, {
  direction: entity.getForward(), // any direction
  length: 20,                     // default 100
  tags: ['enemy'],                // optional: only objects with this tag
  ignore: entity,                 // optional: pass through these (and their children)
  includeMoving: true,            // false = only static scenery
});
if (hit) console.log(hit.entity.name, hit.distance, hit.point, hit.normal);
```

It returns `{ entity, point, normal, distance }`, or `null` when nothing was hit.
