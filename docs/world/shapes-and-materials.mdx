# Shapes & materials

<Art name="cube-water" size={100} />

Anything you can see has a **Shape & look** component. Add a shape from **Objects → ＋ Add → Shapes**, or add the component to any object.

<Side shot="card-mesh" crop>

| Field | What it does |
| --- | --- |
| **Shape** | Cube, Sphere, Plane, Capsule, Cylinder, Cone, Torus (ring), or **3D model (file)**. |
| **Color** | The base color. With a texture, the color tints it (white = the texture as it is). |
| **Texture** | An image wrapped on the shape: one of yours, a new import, or one of the **Free textures** (ground, stone, wood, tiles). |
| **Tiling** | (with a texture) How many times it repeats, U × V. Use it for floors: a 10×10 plane with tiling 10, 10. |
| **Style** | How light falls on it (see below). |
| **Glow color** | Emissive color: the surface shines with it even in the dark. Black = no glow. |
| **Opacity** | 1 = solid, 0 = invisible. |
| **Flat shading** | Faceted, low-poly look. |
| **Casts / Receives shadow** | Whether it throws shadows and shows shadows on itself. |

</Side>

## Material styles

| Style | Look | Speed |
| --- | --- | --- |
| **Matte (fast)** | Soft, no shine. The default — looks good and is fastest on phones. | ⚡⚡⚡ |
| **Realistic** | Physically based: adds **Roughness** and **Metalness** sliders; reflects the sky when *Light with sky* is on. | ⚡ |
| **Cartoon** | Toon shading in bands. | ⚡⚡ |
| **Unlit (flat color)** | Ignores lights completely — always the exact color. Good for skies, UI-like objects, glowing things. | ⚡⚡⚡ |

### Extras on a material

| Setting | What it does |
| --- | --- |
| **Steps** | With **Cartoon**: how many bands of light (2–8). 2 is a flat comic look. |
| **Double sided** | Draw both faces. Use it for flat text, planes and leaves you see from behind. |
| **Outline** | A colored line around the object (0 = off). It works on shapes, 3D text and imported models, including animated characters. **Outline color** picks the color. |
| **Outline fixed on screen** | On: the line is the same thickness on screen at any distance. Off: it is part of the object and shrinks when it is far away. |

The outline is a second copy of the object drawn slightly bigger behind it, so it costs about one extra object. That is cheap for a few characters; don't put it on hundreds of things.

## 3D text

**Objects → ＋ Add → Text (3D)** puts words in the world as real letters. Select it and use the **Mesh** card (Shape: *Text (3D)*):

| Setting | What it does |
| --- | --- |
| **Text** | The words. New lines are allowed; each line is centered. |
| **Font** | One of your fonts, or the built-in one. |
| **Depth** | How thick the letters are. **0 makes them flat**: just the shape of the letters, shown from both sides. |
| **Bevel** | Rounded edges on thick letters. |
| **Style** | Flat text only: **Filled**, **Lines only** (just the outline of each letter) or **Filled + lines**. |
| **Line color** | The color of those lines (the material's color if you don't pick one). |

For a see-through blueprint look, make the text flat, set **Style** to *Filled + lines*, and lower the material's **Opacity** to about 0.4. The size of the object (its **Scale**) is the height of the letters in meters. Change the words while playing with **Set text** (or `entity.setText()`).

## Sizes

Shapes are 1 m across at scale 1 (the plane is 1×1 m; a new Plane is scaled 10×10). Change the size with **Scale** in the Transform card, or the Scale gizmo.

## Changing looks while playing

Actions: **Set color**, **Set opacity**, **Set visible**, **Tween** (smoothly animate opacity, size, position…). Scripts: `entity.setColor('#ff0')`, `entity.setOpacity(0.5)`.
