# Shapes & materials

<Art name="cube-water" size={100} />

Anything you can see has a **Shape & look** component. Add a shape from **Objects → ＋ Add → Shapes**, or add the component to any object.

<Side shot="card-mesh" crop>

| Field | What it does |
| --- | --- |
| **Shape** | Cube, Sphere, Plane, Capsule, Cylinder, Cone, Torus (ring), or **3D model (file)**. |
| **Color** | The base color. With a texture, the color tints it (white = the texture as it is). |
| **Texture** | An image wrapped on the shape: one of yours, a new import, or one of the **Free textures** (ground, stone, wood, tiles). |
| **Tiling** | (with a texture) How many times it repeats, U × V. Use it for floors: a 10×10 plane with tiling 10, 10. |
| **Style** | How light falls on it (see below). |
| **Glow color** | Emissive color: the surface shines with it even in the dark. Black = no glow. |
| **Opacity** | 1 = solid, 0 = invisible. |
| **Flat shading** | Faceted, low-poly look. |
| **Casts / Receives shadow** | Whether it throws shadows and shows shadows on itself. |

</Side>

## Material styles

| Style | Look | Speed |
| --- | --- | --- |
| **Matte (fast)** | Soft, no shine. The default — looks good and is fastest on phones. | ⚡⚡⚡ |
| **Realistic** | Physically based: adds **Roughness** and **Metalness** sliders; reflects the sky when *Light with sky* is on. | ⚡ |
| **Cartoon** | Toon shading in bands. | ⚡⚡ |
| **Unlit (flat color)** | Ignores lights completely — always the exact color. Good for skies, UI-like objects, glowing things. | ⚡⚡⚡ |
| **Reflector (Mirror)** | A mirror: shows the scene reflected in it (see [Mirror](#mirror)). | ⚡ per mirror in view |

### Glass and coatings (Realistic)

On a **Realistic** material these sliders turn on the extra looks of a physically based material. All are 0 (off) until you move them.

| Setting | What it does |
| --- | --- |
| **Transmission** | Glass: 0 is solid, 1 is clear. What is behind shows through, bent and blurred by the roughness. |
| **Thickness** | With glass: how thick it is, in meters. A thick glass ball bends and tints more. |
| **IOR** | With glass: how much it bends light. 1.5 is glass, 1.33 water, 2.4 diamond. |
| **Clear coat** | A glossy clear layer on top, like car paint or a lacquered table. |
| **Sheen** | A soft glow at the edges, like velvet or cloth. |
| **Iridescence** | Rainbow colors that shift with the angle, like a soap bubble or oil on water. |

**Transmission is the costly one.** The game draws the scene a second time to see through the glass, so use it on a few objects (a window, a bottle), not many. For cheap see-through, use **Opacity**.

### Video

Pick a **Video** (an `.mp4` or `.webm` you imported in Files) and it plays on the surface instead of a **Texture**: a TV screen, a cinema, a billboard, a security monitor. Use a **Plane** or a **Cube** and the **Unlit** style, so the picture is as bright as the video.

- The video starts when the game starts, is **muted** and **loops**. Phones only let a game start video by itself when it is muted, and some wait for the first tap.
- **Play, pause or restart** it while playing with the action **Video** on the object (*Play*, *Pause*, *Restart*), or `entity.video.play()`, `.pause()`, `.restart()` and `entity.video.playing` in a script. Objects showing the same video share it, so pausing one pauses all.
- It does not work with **Custom shader** materials.
- Keep videos short and small (a few seconds at 480 p is plenty): the whole file is loaded into the game, and a game exported as one HTML file carries it inside.
- The editor view only redraws when something changes, so the video moves for sure when you press Play.

### Mirror

Set a **Plane** shape to the **Reflector (Mirror)** style and it reflects the scene: a bathroom mirror, a shiny floor, a pool of still water. The **Color** tints the reflection (white is a perfect mirror), and **Reflection size** (128, 256, 512 or 1024) sets how sharp it is. Tilt the plane to make a wall mirror.

- A mirror draws the scene a second time, but only while it is on screen and facing the camera. Several mirrors in view add up, so keep to one or two, and choose a smaller **Reflection size** on phones. A low *Max pixel ratio* makes the picture smaller by itself.
- A mirror seen inside another mirror shows what it drew last, not an endless tunnel.
- In the editor view a mirror is shown as polished metal; you see the real reflection when you play.
- On a shape that is not a Plane, the Mirror style is polished metal (it reflects the sky when *Light with sky* is on), not a true reflection.

### Extras on a material

| Setting | What it does |
| --- | --- |
| **Steps** | With **Cartoon**: how many bands of light (2–8). 2 is a flat comic look. |
| **Double sided** | Draw both faces. Use it for flat text, planes and leaves you see from behind. |
| **Outline** | A colored line around the object (0 = off). It works on shapes, 3D text and imported models, including animated characters. **Outline color** picks the color. |
| **Outline fixed on screen** | On: the line is the same thickness on screen at any distance. Off: it is part of the object and shrinks when it is far away. |

The outline is a second copy of the object drawn slightly bigger behind it, so it costs about one extra object. That is cheap for a few characters; don't put it on hundreds of things.

## 3D text

**Objects → ＋ Add → Text (3D)** puts words in the world as real letters. Select it and use the **Mesh** card (Shape: *Text (3D)*):

| Setting | What it does |
| --- | --- |
| **Text** | The words. New lines are allowed; each line is centered. |
| **Font** | One of your fonts, or the built-in one. |
| **Depth** | How thick the letters are. **0 makes them flat**: just the shape of the letters, shown from both sides. |
| **Bevel** | Rounded edges on thick letters. |
| **Style** | **Filled**, **Lines only** (just the outline of each letter) or **Filled + lines**. |
| **Line color** | The color of those lines (the material's color if you don't pick one). |
| **Line width** | How thick the lines are, in pixels (default 2). |

For a see-through blueprint look, make the text flat, set **Style** to *Filled + lines*, and lower the material's **Opacity** to about 0.4. The size of the object (its **Scale**) is the height of the letters in meters. Change the words while playing with **Set text** (or `entity.setText()`).

## Sizes

Shapes are 1 m across at scale 1 (the plane is 1×1 m; a new Plane is scaled 10×10). Change the size with **Scale** in the Transform card, or the Scale gizmo.

## Changing looks while playing

Actions: **Set color**, **Set opacity**, **Set visible**, **Tween** (smoothly animate opacity, size, position…). Scripts: `entity.setColor('#ff0')`, `entity.setOpacity(0.5)`.
